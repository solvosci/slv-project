In projects where the use of timesheets is allowed, an option is enabled to automatically create a default "Task 0" dedicated to Project Management.

If the timesheet feature is not enabled, the creation of this task will not be allowed.
When timesheets are enabled, it will be possible to choose—directly from the project creation form—whether or not to automatically generate this management task.

From the company settings, a 'Management Task' section has been created that allows selecting the title and description of the management task that is generated automatically.
